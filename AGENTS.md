# Agent Guidelines for trawangan

Petunjuk dan konvensi pengembangan untuk AI agent di repositori `trawangan`.

## Agent skills

### Issue tracker

Issues and specs live in GitHub Issues (`KaleksananBarqi/trawangan`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical triage roles map 1:1 to GitHub issue labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repository layout (`GLOSSARY.md` and `docs/adr/` at repo root). See `docs/agents/domain.md`.
