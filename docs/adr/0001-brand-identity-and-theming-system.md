# 0001. Brand Identity, Signature Theme, and Pure Charting Scope

Untuk membedakan aplikasi dari platform charting komersial, `trawangan` (ditulis dengan huruf kecil) mengadopsi filosofi Jawa *penerawangan* (ꦠꦿꦮꦔꦤ꧀ — visi menembus kabut manipulasi pasar) dengan batasan ruang lingkup murni pada analisis teknikal grafis dan pengujian skrip (zero trade execution / zero brokerage) pada rilis awal.

Secara visual, aplikasi menyimpang dari skema konvensional hijau/merah dengan menetapkan tema bawaan (*Signature Theme*): latar belakang kanvas `#0F0F0F`, candlestick *bullish* serba putih `#F7F7F7`, serta candlestick *bearish* dan aksen visual bermotif *hot pink* `#FF69B4`. Pilihan ini memberikan identitas cyberpunk minimalis yang unik sekaligus mengurangi kelelahan mata (*eye fatigue*) trader. Pilihan tema klasik (Binance, TradingView, Bitunix, Coinglass) tetap disediakan sebagai *preset* sekunder untuk kompatibilitas kebiasaan pengguna.

Identitas tipografi brand `trawangan` distandarkan menggunakan font *Plus Jakarta Sans Extra Bold* (800) untuk menyelaraskan karakter visual geometris logo monogram `tr`. Antarmuka menyediakan fleksibilitas kustomisasi font UI (Inter, Roboto, System) dan font monospace angka/kode (JetBrains Mono, Fira Code, Consolas) serta skala densitas tampilan (Compact, Regular, Comfortable).
