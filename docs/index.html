Akeh platform charting sing ngunci fitur dhasar nang mburi langganan wulanan larang. trawangan mbalekno meja riset 100% gratis nang laptopmu: latar peteng matte Signature sing adem nang mata, tanpa iklan popup sing nggarai emosi, lan database SQLite 100% lokal.

Kendali Kilat nang Drijimu

  • Shift + D / ~
    Draw by Holding & Scribble Erase

    Tahan tombol terus gores nang kanvas gawe nggambar cepat; coret zig-zag gawe mbusek.

  • Ctrl + K
    Omni Symbol Search

    Ketik langsung huruf nang kanvas gawe mbukak kripto, makro TOTAL/BTC.D, IDX, utawa COMEX.

  • Alt + Z / F
    Auto-Fit & Invert Scale (Alt + I)

  • Ctrl + Shift + P
    Bukak Tab Plan (Docked Preview)

  • Ctrl + Shift + S
    Snapshot Ultra HD Side Panel

    Salin gambar chart bening (sampek 6x) lengkap karo kartu tesis nang sebelah tengen.

  • Alt + E
    Side-by-Side Pine Script v6 IDE

    Bukak/tutup editor skrip PineTS CodeMirror 6 tanpa nutup chart utama.
